# Contributing

Help make AI infrastructure easier to understand.

1. Search existing entries before adding a provider or model.
2. Use official documentation, model-card and license URLs.
3. Classify hosted APIs, open-weight models and local runtimes accurately.
4. Never guess pricing, quotas, rate limits, benchmarks or uptime.
5. Include a review date and explain uncertainty.
6. Keep the site accessible, responsive and dependency-light.
7. Do not add analytics, trackers, API proxies or credential collection.

For model submissions, include the exact model page and license URL—not only a provider homepage. Explain whether weights, code and training data are actually available. Open an issue for substantial changes before a large pull request.
